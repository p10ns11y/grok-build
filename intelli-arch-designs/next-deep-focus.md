## The one deep thing

**Measure EVA itself.**

Unit of account: **done work / $** (task finished, **no extra re-prompt**).  
`tool_mix` = invoices. HUD % = sticker.

Question to falsify:

> On *blank-sheet* tasks, EVA (Prior → Probe → Simulate → Score → ActOrAsk) raises done-work per dollar vs skip. On *greppable* tasks, EVA is a cost leak.

If greppable EVA wins, the skip gate is wrong. If blank-sheet EVA loses, the triad is theater. Either way you learn more than another skill file.
